# ‌Wordly ‌Dictionary

## ‌About This Project

Wordly Dictionary is a web app that allows users to search for English words and their definition.

## Features

- Search a word.
- See the definition, part of speech, and example (if exist).
- See the synonyms and pronunciation (if exist).
- Add the word to favorites.
- Change light and dark themes.
- See an error message if the word cannot be searched or the API is down.

## Technologies

- HyperText Markup Language (HTML)
- Cascading Style Sheets (CSS)
- JavaScript (JS)
- Free Dictionary API

## How To Run

1. Download or clone this repository.
2. Open this project folder with Visual Studio Code.
3. Open `index.html` with Live Server.

## Note

The dictionary API might be down occasionally and might not return the word you're looking for.
